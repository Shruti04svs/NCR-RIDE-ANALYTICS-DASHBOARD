## Advanced-Excel-Project

This project analyzes NCR ride-booking data using an interactive Excel dashboard.

### NCR Ride Analytics (Advance Excel Project)

### Overview
This project analyzes ride-booking data from the NCR region to evaluate booking performance, revenue generation, customer behavior, and vehicle usage trends. The final Excel dashboard provides a consolidated view of ride activity using KPIs, charts, and slicers for interactive analysis.

### Tools Used

Microsoft Excel
Pivot Tables
Charts (Line, Bar, Pie, Donut)
Slicers for Booking Status, Vehicle Type, and Driver Ratings

### Project Workflow

Data Collection: Imported raw NCR ride-booking data into Excel.
Data Cleaning: Standardized data formats, handled missing values, and categorized booking statuses and vehicle types.
Pivot Analysis: Created summaries for total rides, revenue, distance, ratings, payment methods, and locations.
Dashboard Design: Built an interactive dashboard with KPI cards, charts, and slicers for dynamic filtering.

### Key Insights

Total Rides: 18,799 rides recorded across the NCR region.
Total Revenue: ₹65,46,278 generated from completed rides.
Average Distance: Average ride distance was 17 km.
Average Rating: Overall average driver rating was 3.
Booking Status: Completed rides formed the majority, followed by cancellations and “No Driver Found” cases.
Peak Month: May recorded the highest number of bookings (1,661 rides).
Payment Method: UPI was the most preferred payment mode, followed by Cash and Wallet payments.
Vehicle Type: Auto and Go Mini contributed the highest number of bookings.
Top Pickup Locations: Subhash Chowk and DLF Phase 3 ranked among the most frequent pickup points.
